## What This Is

A single-file, self-contained portfolio (`index.html`) built with vanilla HTML, CSS, and JavaScript — no build tools, no dependencies, no bundler. Everything is inline so it works as a static Vercel deployment and as a Claude Artifact.

## Deployment

- **GitHub → Vercel auto-deploy**: every push to `main` triggers a production deploy on Vercel automatically.
- No manual deploy step needed — just `git push`.

```bash
cd E:\darshanwala-portfolio
git add .
git commit -m "your message"
git push
```
